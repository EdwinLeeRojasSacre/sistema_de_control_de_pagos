# Changelog

Los cambios relevantes del proyecto se documentan en este archivo, siguiendo el enfoque de [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/).

## [1.0.0]

### Añadido

- Autenticación JWT, perfiles, cambio y restablecimiento de contraseña.
- Control de acceso para `ADMINISTRADOR`, `SECRETARIA` y `DIRECCION`.
- Gestión de usuarios, períodos escolares y estructura académica.
- Registro, consulta, edición e importación de familias.
- Registro, consulta, cambio de aula e importación de matrículas.
- Registro de pagos de APAFA y Taller con vouchers asociados.
- Consulta, reasignación controlada y eliminación de vouchers.
- Reportes institucionales y exportaciones XLSX/PDF.
- Auditoría de operaciones sensibles y validaciones de integridad.
- Pruebas unitarias, HTTP E2E y regresiones contra base de desarrollo aislada.
