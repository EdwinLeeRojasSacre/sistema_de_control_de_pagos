# Desinstalación

La desinstalación elimina los servicios, la tarea programada, accesos directos y binarios de `C:\Program Files\Sistema de Control de Pagos`. Por seguridad conserva `C:\ProgramData\SistemaControlPagos` y la base PostgreSQL, incluidos configuración, vouchers, logs y respaldos.

Después de verificar un respaldo externo, un administrador puede eliminar manualmente esos datos y la base. El desinstalador nunca borra automáticamente información institucional.
