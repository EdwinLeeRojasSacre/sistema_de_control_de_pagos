# Frontend — Sistema de Control de Pagos

Interfaz web de la versión 1.0.0 del Sistema de Control de Pagos de la I.E.I. Cuna Jardín N.° 85 “María Inmaculada Concepción” — Chancay.

Está construida con Next.js, React, TypeScript y Tailwind CSS. Consume la API REST del backend y presenta las funciones autorizadas para `ADMINISTRADOR`, `SECRETARIA` y `DIRECCION`.

## Configuración

Copie `.env.example` como `.env.local` y configure la URL pública de la API.

```bash
npm ci
npm run dev
```

La aplicación queda disponible por defecto en `http://localhost:3000`.

## Comandos principales

```bash
npm run lint
npm run build
npm run start
```
